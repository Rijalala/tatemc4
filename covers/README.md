# Folder Cover Gambar Tate McRae

Taruh foto atau thumbnail cover kustom (`.jpg`, `.jpeg`, `.png`, atau `.webp`) di folder ini jika ingin mengganti cover lagu tertentu.

### 💡 Sistem Prioritas Cover:
1. **Prioritas Utama (Kustom)**: Jika ada file foto kamu di folder `covers/` (misalnya `covers/greedy.jpg` atau `covers/hard.jpg`), web akan langsung memprioritaskan dan menampilkan foto tersebut!
2. **Fallback Otomatis**: Jika tidak ada foto yang kamu tambahkan, web menggunakan cover official album aslinya.
3. **Jika Dihapus**: Jika kamu menghapus foto kustommu dari folder ini lalu me-refresh web, tampilannya akan **otomatis kembali ke cover official aslinya** tanpa error!
